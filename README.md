# cauqui-nao-obfuscado
Versão não obfuscada (mas mais pesada) do cauqui, uma calculadora extremamente simples escrita em C.
Se você quiser ver o código fonte e examinar ele, recomendo usar esse repositório, porque o código fonte do repositório original contém código bem obfuscado (para deixar o programa mais leve). Mas se você quiser apenas usar o programa recomendo
baixar pelo outro repositório.
